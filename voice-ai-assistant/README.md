# Voice AI Assistant (Python)

A simple voice-enabled AI assistant that converts speech to text, processes it, and responds using text-to-speech.

---

## Features
- Speech-to-Text using SpeechRecognition
- Text-to-Speech using gTTS
- Continuous voice conversation loop
- Python-based AI assistant

---

##  Tech Stack
Python, SpeechRecognition, gTTS, PyAudio

---

##  How to Run
```bash
pip install -r requirements.txt
python app.py
